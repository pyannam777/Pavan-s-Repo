MONEY TRACKER - how to put it online (free)

This folder is a complete web app. It must be opened from a web link (not as a file) to install on a phone.
Your numbers are saved only on each person's own device. Nothing is uploaded.

OPTION A - GitHub Pages (stable link)
1. Create a free GitHub account, then a new public repository (for example: money-tracker).
2. Upload ALL files from this folder (index.html, manifest.webmanifest, sw.js and the .png icons).
3. Repository Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. After a minute your link is https://YOURNAME.github.io/money-tracker/

OPTION B - Netlify Drop
1. Go to app.netlify.com/drop and drag this whole folder onto the page.
2. Netlify gives you a link. Create a free account to keep it permanently.

OPTION C - Cloudflare Pages (Direct Upload): upload this folder.

INSTALL ON A PHONE
iPhone: open the link in Safari > Share > Add to Home Screen.
Android: open the link in Chrome > menu > Install app.

BACKUP: use "Download backup" at the bottom of the app each month.
